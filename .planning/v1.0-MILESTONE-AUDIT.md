### Remaining Integration Gaps

**GAP-01: SQLite audit_log missing metadata column (Moderate)**
- **Affects:** SAFE-11, INTF-03, POC-03
- **Location:** `src/state/db.ts` lines 19-30, `src/state/store.ts` line 140
- **Impact:** Execution events (lock_acquired, step_complete, circuit_breaker_triggered, etc.) carry payload in `entry.metadata`. Written to `audit.jsonl` but not SQLite. `/infra:history` shows empty summaries for execution events via HTTP path.
- **Fix:** Add `metadata TEXT` column; persist `JSON.stringify(entry.metadata)` in INSERT.

**GAP-02: Log-analysis parsers not wired into runtime (Low)**
- **Affects:** SKIL-03, SKIL-04
- **Location:** `src/log-analysis/` — 4 parsers, detector, filter (all unit-tested)
- **Impact:** The LLM handles log analysis via skill prompt alone. Node.js token-budget-aware pre-filtering is not activated. Functionally correct but suboptimal token usage.
- **Fix:** Wire `preFilterLogs` into debug route for log-heavy prompts.

**GAP-03: RollingContext not consumed in executor (Low)**
- **Affects:** CORE-07
- **Location:** `src/execution/executor.ts` — `getContext()` never called
- **Impact:** Step results accumulated but not injected into subsequent LLM calls. Each step executes independently.
- **Fix:** Inject `rollingContext.getContext()` into sub-agent LLM calls.
