<objective>
Fix plan session resumability with auto-detect, explicit resume command, retry/skip choice, and stale session warnings.

Purpose: When a fix plan is interrupted (circuit breaker, damage budget, admin rejection, crash), the admin can pick up where they left off instead of re-running completed steps. This is critical for long fix plans where re-running already-successful steps wastes time and risks double-applying changes.

Output: Working /infra:resume command, auto-detect on /infra:debug, executor resume-from-step capability.
</objective>
