  <files>src/state/store.ts, src/cli/time-parser.ts, src/api/routes/history.ts, src/api/server.ts, tests/state/history-query.test.ts</files>

    - queryAuditLog({}) returns last 20 entries ordered by timestamp DESC
    - queryAuditLog({ sessionId: 'abc' }) returns only entries for that session
    - queryAuditLog({ eventType: 'approval', riskLevel: 'destructive' }) returns entries matching BOTH filters (AND)
    - queryAuditLog({ since: '2026-01-01T00:00:00.000Z', until: '2026-12-31T...' }) returns entries in range
    - queryAuditLog({ limit: 5 }) returns at most 5 entries
    - parseTimeInput('1h ago') returns ISO string ~1 hour before now
    - parseTimeInput('30m ago') returns ISO string ~30 min before now
    - parseTimeInput('2d ago') returns ISO string ~2 days before now
    - parseTimeInput('2026-03-08T12:00:00.000Z') returns the same ISO string
    - parseTimeInput('garbage') throws Error
    - GET /history returns audit entries with default limit 20
    - GET /history?type=approval&risk=destructive returns filtered entries
  </behavior>
  <action>
    1. Create `src/cli/time-parser.ts`:
       - Export `parseTimeInput(input: string): string` -- returns ISO 8601 string
       - Try `new Date(input)` first -- if valid, return `.toISOString()`
       - Else match `/^(\d+)\s*(s|m|h|d)\s*(?:ago)?$/i` for relative time
       - Multipliers: s=1000, m=60000, h=3600000, d=86400000
       - Return `new Date(Date.now() - amount * multiplier).toISOString()`
       - Throw `Error` with helpful message on invalid input

    2. Add `AuditQueryFilters` interface and `queryAuditLog` method to `src/state/store.ts`:
       - Interface: `{ sessionId?: string; eventType?: string; riskLevel?: string; since?: string; until?: string; limit?: number }`
       - Build WHERE clause dynamically with parameterized `?` placeholders (see research pattern 3)
       - ORDER BY timestamp DESC LIMIT (filters.limit ?? 20)
       - Use `this.db.prepare().all()` -- synchronous, no async needed
       - Return parsed rows as `AuditEntry[]` (map column names to camelCase: session_id -> sessionId, event_type -> eventType, risk_level -> riskLevel, diff_before -> diffBefore, diff_after -> diffAfter)

    3. Create `src/api/routes/history.ts`:
       - Export `createHistoryRoute(deps: { store: WriteThrough }): Router`
       - GET / handler reads query params: `session`, `type`, `risk`, `since`, `until`, `limit`, `verbose`
       - Convert `since`/`until` via parseTimeInput before passing to store
       - Pass to `store.queryAuditLog(filters)`
       - Return `{ entries, count: entries.length, filters: { applied filters } }`

    4. Mount in `src/api/server.ts`:
       - Import createHistoryRoute
       - Mount: `app.use('/history', createHistoryRoute({ store }))` -- only if store available

    5. Tests in `tests/state/history-query.test.ts`:
       - Set up in-memory SQLite with initDatabase, insert 10+ diverse audit entries
       - Test each filter individually and combined (AND logic)
       - Test limit, default 20
       - Test parseTimeInput with relative and ISO inputs
       - Test GET /history via supertest with mocked store
  </action>
