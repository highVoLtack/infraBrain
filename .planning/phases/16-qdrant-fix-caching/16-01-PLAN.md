  <name>Task 1: Cache types, config schema, and confidence scoring</name>
  <files>src/cache/types.ts, src/cache/confidence.ts, src/config/types.ts, tests/cache/confidence.test.ts</files>
  <behavior>
    - computeConfidence(similarity=0.90, ageDays=0, successRate=1.0) with default weights returns 0.5*0.90 + 0.3*1.0 + 0.2*1.0 = 0.95
    - computeConfidence(similarity=0.90, ageDays=30, successRate=0.5) returns lower score due to exponential decay
    - computeConfidence with zero total uses returns neutral 0.5 success rate
    - Exponential decay: recency_score = Math.exp(-lambda * ageDays), where lambda is configurable
    - Default weights: w_sim=0.5, w_rec=0.3, w_suc=0.2
  </behavior>
  <action>
    1. Install LanceDB: `npm install @lancedb/lancedb`

    2. Create `src/cache/types.ts` with:
       - `CacheEntry` interface: id (string), vector (number[]), error_signature (string), skill_name (string), fix_plan (string -- JSON-serialized FixPlan), diagnosis (string), session_id (string), created_at (string ISO), last_used (string ISO), hit_count (number), success_count (number), fail_count (number)
       - `CacheHit` interface: similarity (number), confidence (number), entry (CacheEntry)
       - `CacheResult` type: { type: 'fast-path', hit: CacheHit } | { type: 'speculative', hit: CacheHit } | { type: 'miss' }
       - `CacheConfig` interface: enabled (boolean), similarity_threshold (number, default 0.85), soft_zone_floor (number, default 0.75), data_dir (string)
       - `ConfidenceConfig` interface: w_sim (number), w_rec (number), w_suc (number), decayLambda (number)
       - `DEFAULT_CACHE_CONFIG` and `DEFAULT_CONFIDENCE_CONFIG` constants

    3. Create `src/cache/confidence.ts`:
       - `computeConfidence(similarity, lastUsed, successCount, totalUses, config)` per CONTEXT.md formula
       - `confidence = w_sim * similarity + w_rec * recencyScore + w_suc * successRate`
       - recencyScore = Math.exp(-config.decayLambda * ageDays)
       - successRate = totalUses > 0 ? successCount / totalUses : 0.5 (neutral default)
       - Export the function

    4. Extend `src/config/types.ts` InfraBrainConfigSchemaInner:
       - Add `cache` field with zod schema: `z.object({ enabled: z.boolean().default(true), similarityThreshold: z.number().default(0.85), softZoneFloor: z.number().default(0.75), dataDir: z.string().default('.infrabrain/cache'), confidenceWeights: z.object({ w_sim: z.number().default(0.5), w_rec: z.number().default(0.3), w_suc: z.number().default(0.2), decayLambda: z.number().default(0.1) }).default({}) }).default({})`

    5. Create `tests/cache/confidence.test.ts` with the behavior cases above.
  </action>

  <files>src/cache/lance-store.ts, src/cache/embedder.ts, tests/cache/lance-store.test.ts, tests/cache/embedder.test.ts</files>
  <behavior>
    - LanceDB store: getCacheStore(dataDir) returns singleton CacheStore
    - CacheStore.ensureTable() creates fix_cache table with 1024-dim vector column if not exists
    - CacheStore.search(embedding, limit) returns rows with _distance field
    - CacheStore.add(entry) inserts row with vector + payload columns
    - CacheStore.deleteBySkill(skillName) removes entries where skill_name matches
    - CacheStore.deleteAll() purges entire table
    - CacheStore.listAll() returns all entries (for CLI)
    - CacheStore.updateStats(id, updates) updates hit_count/success_count/fail_count/last_used
    - Embedder: formatEmbeddingInput(userPrompt, filteredDiscovery) concatenates "ERROR: {prompt}\n\nCONTEXT:\n{discovery}"
    - Embedder: generateEmbedding(text, baseURL, modelId) returns number[] of length 1024
  </behavior>
  <action>
    1. Create `src/cache/lance-store.ts`:
       - Singleton pattern: `_stores = new Map<string, CacheStore>()` keyed by dataDir
       - `getCacheStore(dataDir)` returns existing or creates new CacheStore
       - CacheStore class wraps lancedb.Connection:
         - `constructor(dataDir)` stores dir path, lazy-inits connection
         - `async init()` calls `lancedb.connect(dataDir)`, creates/opens fix_cache table
         - Table schema: vector (FixedSizeList 1024 Float32), plus all CacheEntry string/number fields
         - Use `createEmptyTable` for initial creation if table doesn't exist, `openTable` if it does
         - `async search(embedding: number[], limit = 5)`: vectorSearch with cosine distance, returns raw rows
         - `async add(entry: Omit<CacheEntry, 'id'>, vector: number[])`: adds row with randomUUID id
         - `async deleteBySkill(skillName: string)`: `table.delete(\`skill_name = '${skillName}'\`)`
         - `async deleteAll()`: drop and recreate table
         - `async listAll()`: table scan toArray()
         - `async updateStats(id, updates)`: update row by id filter
       - ALL methods wrapped in try-catch returning null/empty on failure (graceful degradation per CACHE-07)

    2. Create `src/cache/embedder.ts`:
       - `formatEmbeddingInput(userPrompt, filteredDiscovery)`:
         - Concatenates `ERROR: ${userPrompt}\n\nCONTEXT:\n${discoveryEntries}`
         - discoveryEntries = Object.entries(filteredDiscovery).map(([k,v]) => `${k}: ${v}`).join('\n')
       - `generateEmbedding(text, baseURL, modelId)`:
         - Uses `embed()` from 'ai' with `createOpenAICompatible` provider (same pattern as openai-compat.ts)
         - Creates provider via `createOpenAICompatible({ name: 'infrabrain-embed', baseURL })`
         - Gets embedding model via `provider.textEmbeddingModel(modelId)`
         - Calls `embed({ model, value: text })` and returns `embedding`
         - Asserts embedding.length === 1024 (BGE-M3 dimension)
       - `isEmbeddingAvailable(baseURL, modelId)`: quick health check, returns boolean
       - All wrapped in try-catch returning null on failure (graceful degradation)
