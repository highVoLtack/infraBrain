    - checkCache with similarity < 0.75 returns { type: 'miss' }
    - checkCache with null store returns { type: 'miss' } (graceful degradation)
    - checkCache with embedding failure returns { type: 'miss' }
    - storeFixInCache writes entry after successful execution
    - hashSkillFiles returns Map of filename to SHA-256 hash
    - runStartupInvalidation compares current hashes to stored hashes and purges changed skills
    - runStartupInvalidation with store failure does not throw (graceful degradation)
  </behavior>
  <action>
    1. Create `src/cache/cache-lookup.ts`:
       - `async checkCache(params)` where params: `{ prompt: string, filteredDiscovery: Record<string, string>, store: CacheStore | null, baseURL: string, modelId: string, cacheConfig: CacheConfig, confidenceConfig: ConfidenceConfig }`
         - If !store or !cacheConfig.enabled, return { type: 'miss' }
         - Call formatEmbeddingInput(prompt, filteredDiscovery)
         - Call generateEmbedding(text, baseURL, modelId) -- if null, return { type: 'miss' }
         - Call store.search(embedding, 1) -- if empty, return { type: 'miss' }
         - Convert distance to similarity: `similarity = 1 - row._distance`
         - Call computeConfidence(similarity, lastUsed, successCount, totalUses, confidenceConfig)
         - Classify: >= similarityThreshold -> 'fast-path', >= softZoneFloor -> 'speculative', else -> 'miss'
         - On fast-path/speculative, increment hit_count via store.updateStats
         - Return CacheResult with CacheHit containing similarity, confidence, and entry

       - `async storeFixInCache(params)` where params: `{ prompt: string, filteredDiscovery: Record<string, string>, diagnosis: string, fixPlan: FixPlan, skillName: string, sessionId: string, store: CacheStore | null, baseURL: string, modelId: string }`
         - Generate embedding from formatEmbeddingInput
         - Call store.add with CacheEntry payload (hit_count=0, success_count=0, fail_count=0, timestamps=now)
         - Return void, all errors caught silently (cache write failure is not critical)

       - `async recordFixOutcome(store: CacheStore | null, entryId: string, succeeded: boolean)`:
         - If succeeded, increment success_count; else increment fail_count
         - Update last_used timestamp

    2. Create `src/cache/invalidation.ts`:
       - `hashSkillFiles(skillsDir: string): Map<string, string>`:
         - Read all .md files in skillsDir
         - SHA-256 hash each file's content
         - Return Map<filename, hash>
       - `async runStartupInvalidation(store: CacheStore | null, skillsDir: string, storedHashesPath: string)`:
         - If !store, return early
         - Compute current hashes via hashSkillFiles
         - Read stored hashes from JSON file at storedHashesPath (if exists)
         - For each skill where hash differs (or skill is new): call store.deleteBySkill(skillName without .md extension)
         - Write current hashes to storedHashesPath
         - Log purged skills to console in DEV_MODE
         - All wrapped in try-catch (graceful degradation)

    3. Create `tests/cache/cache-lookup.test.ts`:
       - Mock store, embedder, confidence

       - Test graceful degradation (null store, failed embedding)
       - Test storeFixInCache writes correctly
       - Test recordFixOutcome updates stats

    4. Create `tests/cache/invalidation.test.ts`:
       - Use temp dir with mock skill files
       - Test: first run creates hash file, no purges
       - Test: modified skill file triggers deleteBySkill for that skill only
       - Test: unchanged skills are not purged
       - Test: new skill file does not cause purge (no cached entries to purge)
