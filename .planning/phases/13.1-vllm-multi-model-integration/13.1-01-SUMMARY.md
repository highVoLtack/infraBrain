## Accomplishments
- Unified provider module (src/llm/openai-compat.ts) creates LanguageModel instances via @ai-sdk/openai-compatible

## Decisions Made
- Used z.preprocess (not z.transform) for ollamaBaseUrl migration -- preprocess runs before schema validation, cleanest for field renaming
- Default baseURL includes /v1 suffix (http://localhost:11434/v1) -- Ollama's OpenAI compat endpoint requires it, avoids 404 pitfall
- supportsStructuredOutputs: true set at provider level -- enables vLLM guided decoding for generateObject calls
- OLLAMA_HEALTH_URL kept as deprecated alias for DEFAULT_HEALTH_URL -- Plan 02 will migrate callers
- defaultBaseUrl takes precedence when both ollamaBaseUrl and defaultBaseUrl present in config JSON
