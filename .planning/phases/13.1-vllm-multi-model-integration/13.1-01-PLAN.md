<objective>
Create the unified OpenAI-compatible provider module and updated config schema that enables per-role baseURL routing. This is the foundation that Plan 02 wires into all callers.

Output: `src/llm/openai-compat.ts` (drop-in replacement for `ollama.ts`), updated `src/config/types.ts`, and comprehensive unit tests.
