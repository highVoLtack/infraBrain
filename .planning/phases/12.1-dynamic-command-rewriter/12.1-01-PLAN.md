<feature>
  <name>Dynamic Command Rewriter</name>
  <files>src/execution/dynamic-rewriter.ts, tests/execution/dynamic-rewriter.test.ts</files>
  <behavior>
    - dynamicRewrite("SELECT 1", [rule with match "^(SELECT|SHOW)\\b", container "auto", wrapper 'psql -U postgres -c "{cmd}"'], ["pg-container"]) -> 'docker exec pg-container psql -U postgres -c "SELECT 1"'
    - dynamicRewrite("chown 1000:1000 /app/data", [rule with match "^(chown|chmod)\\b", container "auto", user "0"], ["permission-app"]) -> "docker exec -u 0 permission-app chown 1000:1000 /app/data"
    - dynamicRewrite("ls -ld /app/data", [rule with match "^(ls|id|stat)\\b", container "auto"], ["permission-app"]) -> "docker exec permission-app ls -ld /app/data"
    - dynamicRewrite("psql -U postgres -h 172.20.0.2 -c \"SELECT 1\"", [rule with match "^psql\\b", container "auto", strip_flags ["-h", "--host"]], ["pg-container"]) -> 'docker exec pg-container psql -U postgres -c "SELECT 1"'
    - dynamicRewrite("docker exec mycontainer ls", rules, containers) -> "docker exec mycontainer ls" (passthrough, already wrapped)
    - dynamicRewrite("echo hello", [], containers) -> "echo hello" (no rules, passthrough)
    - dynamicRewrite("echo hello", [rule that doesn't match], containers) -> "echo hello" (no match, passthrough)
    - resolveContainer("auto", ["app1", "app2"]) -> "app1" (first container)
    - resolveContainer("specific-name", ["specific-name", "other"]) -> "specific-name"
    - RewriteRuleSchema validates correct rule shape
    - RewriteRuleSchema rejects rule without required match field
    - Strip flags removes both -h value and --host=value forms
    - First matching rule wins -- order matters
  </behavior>
  <implementation>
    Create `src/execution/dynamic-rewriter.ts` as a pure function module:

    1. Define `RewriteRuleSchema` using Zod:
       - `match`: z.string() (required -- regex pattern)
       - `container`: z.string().default('auto')
       - `user`: z.string().optional() (e.g., "0" for root)
       - `wrapper`: z.string().optional() (e.g., 'psql -U postgres -c "{cmd}"')
       - `risk`: z.enum(['read', 'write', 'destructive']).optional()
       - `strip_flags`: z.array(z.string()).optional()

    2. Export `RewriteRule` type inferred from schema.

    3. Implement `dynamicRewrite(command: string, rules: RewriteRule[], containers: string[]): string`:
       - If command starts with `docker exec` -> return unchanged (prevent double-wrapping)
       - Iterate rules in order, test command against `new RegExp(rule.match, 'i')`
       - First match wins: apply strip_flags -> wrapper -> resolve container -> build docker exec with optional -u flag
       - No match -> return command unchanged

    4. Internal `resolveContainer(spec: string, containers: string[]): string | undefined`:
       - "auto" -> containers[0]
       - specific name -> verify exists in containers, fallback to containers[0]

    5. Internal `stripFlags(command: string, flags: string[]): string`:
       - For each flag, strip `-flag value`, `--flag value`, `--flag=value` patterns
       - Collapse multiple spaces

    Follow the reference implementation from RESEARCH.md Pattern 1 closely. Use `.js` extension in imports (ESM project).
  </implementation>
</feature>
