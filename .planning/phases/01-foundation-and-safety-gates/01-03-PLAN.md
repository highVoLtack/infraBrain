Command validation, risk classification, and human-in-the-loop approval gates.

Purpose: Build the safety layer that stands between LLM-generated commands and execution. This is the trust backbone of InfraBrain -- hardcoded blocklists prevent catastrophic commands, risk classification determines the approval UX, and the approval gate ensures human control. Without this, the platform cannot safely interact with infrastructure.

Output: Working command validator (allowlist/blocklist), risk classifier (read/write/destructive/blocked), and approval gate with three tiers of human confirmation.
</objective>

    1. Create src/cli/approval.ts:
       - Import readline from 'node:readline/promises'
       - Import chalk from 'chalk'
       - Import RiskLevel from '../safety/types.js'

       - Export extractTarget(command: string): string
         - Parse the last meaningful argument from the command as the "target"
         - For docker commands: extract container/image name
         - For file commands: extract file path
         - Fallback: last whitespace-separated token

       - Export interface ApprovalResult { approved: boolean, approvalType: 'auto' | 'y_n' | 'typed_confirmation' | 'blocked', command: string, riskLevel: RiskLevel }

       - Export async function requestApproval(command: string, riskLevel: RiskLevel, rl: readline.Interface): Promise<ApprovalResult>
         - RiskLevel.READ: Auto-approve. Log with chalk.gray("[auto-approved] {command}"). Return { approved: true, approvalType: 'auto' }
         - RiskLevel.WRITE: Prompt with chalk.yellow(`Execute "${command}"? [Y/n] `). Default is Y (empty input = approve). Return { approved, approvalType: 'y_n' }
         - RiskLevel.DESTRUCTIVE: Extract target via extractTarget. Prompt with chalk.red(`DESTRUCTIVE: "${command}"\nType "${target}" to confirm: `). Exact match required. Return { approved, approvalType: 'typed_confirmation' }
         - RiskLevel.BLOCKED: No prompt. Return { approved: false, approvalType: 'blocked' }
