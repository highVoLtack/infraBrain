<feature>
  <name>Docker-exec-aware command rewriting</name>
  <files>src/execution/dynamic-rewriter.ts, tests/execution/dynamic-rewriter.test.ts</files>
  <behavior>
    **New parseDockerExec helper:**
    - Parses `docker exec [-flags] <container> <inner-command>` into `{ flags: string[], container: string, inner: string }`
    - Handles value-flags: `-u 0`, `--user 0`, `-e VAR=val`, `-w /dir`, `--workdir /dir`, `--env VAR=val`
    - Handles boolean flags: `-it`, `-i`, `-t`, `--privileged`
    - Returns null if unparseable (no container, no inner command, not a docker exec)

    **Modified dynamicRewrite docker exec branch (replaces lines 98-101):**
    - Parse the docker exec command via parseDockerExec
    - If unparseable, return trimmed (passthrough)
    - Strip -it/-ti/-i/-t from parsed flags (belt-and-suspenders)
    - Try to match inner command against rules (first-match-wins, same as bare-command path)
    - If rule matches:
      - Apply strip_flags to inner command
      - Apply wrapper to inner command (if defined)
      - Inject `-u <user>` if rule has user and flags lack -u/--user (no double-injection)
      - Reassemble: `docker exec [merged-flags] <container> <processed-inner>`
    - If no rule matches: return cleaned docker exec (with -it stripped, everything else preserved)
    - Bare command path (lines 104-136) MUST remain unchanged

    **Test cases (RED phase):**
    - Case A: `docker exec permission-app chown 1000:1000 /app/data` + privilegeRule -> `docker exec -u 0 permission-app chown 1000:1000 /app/data`
    - Case B: `docker exec -u 0 permission-app chown 1000:1000 /app/data` + privilegeRule -> `docker exec -u 0 permission-app chown 1000:1000 /app/data` (no double-inject)
    - Case C: `docker exec -it permission-app ls -ld /app/data` + simpleContainerRule -> `docker exec permission-app ls -ld /app/data` (-it stripped)
    - Case D: `docker exec -it mycontainer echo hello` + sqlRule (no match) -> `docker exec mycontainer echo hello` (-it stripped, passthrough)
    - Case E: `docker exec pg-container psql -U postgres -h 172.20.0.2 -c "SELECT 1"` + stripFlagsRule -> `docker exec pg-container psql -U postgres -c "SELECT 1"` (strip_flags applied to inner)
    - Case F: `docker exec` (no inner command) -> `docker exec` (passthrough)
    - Case G: `docker exec mycontainer` (no inner command) -> passthrough
    - Case H: `docker exec -u 0 -it permission-app chown 1000:1000 /app/data` + privilegeRule -> `docker exec -u 0 permission-app chown 1000:1000 /app/data` (-it stripped, -u 0 preserved, no double-inject)
    - Regression: All 21 existing tests MUST still pass
  </behavior>
