    3. After discovery phase and before diagnosis, restructure the flow:

    ```
    CURRENT SEQUENTIAL FLOW:
      discovery -> noise filter -> compaction -> cache check -> memory enrichment -> diagnosis -> planning

    NEW PARALLEL FLOW (when scheduler.getMode() === 'parallel'):
      discovery -> cache check -> memory enrichment ->
        CONCURRENT:
          a) 9B path: noise filter + compaction (worker model)

        -> merge: if 9B produced cleaner context, it enriches the PLANNING phase
        -> planning

      - Cache check and memory enrichment remain BEFORE the parallel split (they don't use LLM)
      - The 122B diagnosis receives the raw (unfiltered) discovery context -- it can handle noise
      - The 9B noise filter + compaction results enrich the planning phase prompt
      - If 9B fails in parallel mode, planning uses raw context (graceful degradation)
    ```

    4. Implementation approach:
    ```typescript

        const rawEnrichedPrompt = /* ... build from raw discoveryRaw ... */;

        // Launch both concurrently
        const results = await scheduler.runParallel([
          {
            label: '9B-preprocess',
            role: 'worker' as ModelRole,
            execute: async () => {
              const noiseResult = await filterNoise(discoveryRaw, skillNoisePatterns, workerModel);
              // Run compaction on filtered result
              const mgr = new ContextManager(/* ... */);
              mgr.ingestDiscovery(noiseResult.filtered);
              const compResult = await mgr.maybeCompact(workerModel);
              return { noiseResult, contextBlock: mgr.buildContext(), compResult };
            },
          },
          {
            label: '122B-diagnosis',
            role: (preferredRole ?? 'default') as ModelRole,
            execute: async () => {
              return runDiagnosis({
                prompt: rawPreFiltered,
                systemPrompt,
                discoveryContext,
                provider,
                preferredRole,
                rewriteRules,
                targetContainers,
                auditLogger,
              });
            },
          },
        ]);

        // Extract results
        const preProcessResult = results.find(r => r.label === '9B-preprocess');
        const diagResult = results.find(r => r.label === '122B-diagnosis');

        // Use diagnosis result (required -- fail if rejected)
        if (diagResult?.status === 'rejected') {
          throw new Error(`Diagnosis failed: ${diagResult.reason}`);
        }
        const diagnosisResult = diagResult!.value as DiagnosisResult;

        // If 9B succeeded, use its cleaned context for planning enrichment
    ```
