  <name>Task 2: Compactor, snapshot writer, and ContextManager</name>
  <files>src/context/compactor.ts, src/context/snapshot.ts, src/context/context-manager.ts, tests/context/compactor.test.ts, tests/context/context-manager.test.ts</files>
  <behavior>
    - tieredEviction Tier 1: removes observations marked isNoise=true
    - tieredEviction Tier 2: compresses oldest observations (keeps first 2 lines as summary, discards rest), oldest first
    - tieredEviction Tier 3: calls worker model to summarize remaining observations into a single summary observation
    - tieredEviction stops after any tier that brings tokens under target
    - tieredEviction returns EvictionResult with remaining, removed, and optional summary
    - saveSnapshot writes JSON to sessionDir/snapshots/{sessionId}-{timestamp}.json
    - ContextManager.ingestDiscovery adds filtered observations with token counts
    - ContextManager.getUsage returns { tokens, percentage, groundTruthTokens }
    - ContextManager.maybeCompact fires compaction when percentage >= 0.83
    - ContextManager.maybeCompact fires exactly ONCE per threshold crossing (compactionFired flag)
    - ContextManager.maybeCompact saves snapshot before eviction
    - ContextManager.buildContext returns "## Ground Truth\n...\n---\n## Observations\n..."
    - After compaction, usage percentage is at or below 60%
  </behavior>
  <action>
    1. Create `src/context/snapshot.ts`:
       - `saveSnapshot(params: { sessionDir: string, sessionId: string, groundTruth: PinnedFact[], observations: Observation[], tokenCount: number, reason: string }): Promise<string>` -- writes JSON file to `${sessionDir}/snapshots/${sessionId}-${Date.now()}.json`, creates directory if needed, returns file path
    2. Create `src/context/compactor.ts`:
       - `tieredEviction(params: { observations: Observation[], groundTruthTokens: number, windowSize: number, targetRatio: number, workerModel?: LanguageModel }): Promise<EvictionResult>`
       - Tier 1: Filter out observations where `isNoise === true`. Recalculate total. If under target, return.
       - Tier 2: Sort remaining by timestamp ascending (oldest first). For each oldest observation, compress to first 2 lines of content + "...(compressed)". Recalculate tokens with countTokens. If under target, return.
       - Tier 3: If workerModel provided and still over target, call worker model with `generateObject` from `ai` SDK. Prompt: "Summarize these infrastructure diagnostic observations into the key findings only. Remove redundancy." Schema: `{ summary: z.string() }`. Replace all non-ground-truth observations with a single summary observation. If no workerModel, do aggressive Tier 2 (compress to 1 line each).
       - Return `{ remaining, removed, summary }`.
    3. Create `src/context/context-manager.ts`:
       - `class ContextManager`:
         - Constructor takes `ContextManagerConfig` + `sessionDir?: string` + `sessionId?: string`
         - Private state: `groundTruthManager: GroundTruthManager`, `observations: Observation[]`, `totalTokens: number`, `compactionFired: boolean`
         - `ingestDiscovery(filteredRaw: Record<string, string>): void`:
           - Extract ground truth via `extractGroundTruth(filteredRaw)` + `parseExplicitPins(JSON.stringify(filteredRaw))`
           - Add each pinned fact to groundTruthManager
           - Create Observation per discovery key with token count via countTokens
           - Update totalTokens (groundTruthManager.getTokens() + sum of observation tokens)
         - `getUsage(): { tokens: number, percentage: number, groundTruthTokens: number }`:
           - Percentage = totalTokens / windowSize
         - `maybeCompact(workerModel?: LanguageModel): Promise<CompactionResult | null>`:
           - If compactionFired === true, return null (once-per-threshold guard)
           - If percentage < threshold, return null
           - Set compactionFired = true
           - Save snapshot via saveSnapshot
           - Run tieredEviction targeting this.config.target
           - Update observations and totalTokens from eviction result
           - Return CompactionResult
         - `buildContext(): string`:
           - Return groundTruthManager.buildSection() + "\n---\n## Observations\n" + observations joined by "\n\n"
         - `reset(): void` -- clears all state for new session
    4. Write tests:
       - `tests/context/compactor.test.ts`: Test each tier independently, test early-exit when under target, mock worker model for Tier 3
       - `tests/context/context-manager.test.ts`: Test ingestDiscovery populates ground truth + observations, test getUsage percentage, test maybeCompact fires at 83% and targets 60%, test compactionFired prevents double compaction, test buildContext format
  </action>
