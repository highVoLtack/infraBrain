## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 4.0.18 |
| **Config file** | `vitest.config.ts` |
| **Quick run command** | `npx vitest run tests/ui/components.test.tsx --reporter=verbose` |
| **Full suite command** | `npx vitest run` |
| **Estimated runtime** | ~15s (UI subset), ~90s (full suite) |

Notes:
- UI tests use `ink-testing-library@4.0.0` with `lastFrame()` + `toContain()` assertions
  (ANSI-tolerant; no raw snapshot diffing — see RESEARCH.md §6).
- `strip-ansi` is transitively available (via `string-width`) when an ANSI-stripped
  snapshot helper is needed for structural assertions.
- Backend SSE/status tests use existing integration-test scaffolding under
  `tests/api/` (same Vitest config, no new framework).

## Sampling Rate

- **After every task commit:** Run `npx vitest run tests/ui/components.test.tsx --reporter=verbose`
  (and the relevant backend test file if the task touches `src/api/*` or `src/state/*`).
- **After every plan wave:** Run `npx vitest run`.
- **Before `/gsd-verify-work`:** Full suite must be green.
- **Max feedback latency:** 15 seconds (UI subset) / 90 seconds (full suite).
