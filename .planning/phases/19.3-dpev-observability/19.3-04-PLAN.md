    **Rendering (DPEVPanelContent):**

    For each phase (indexed `i`):
    1. Compute `isFocused = state.focusedPhaseIndex === i`.
    2. Compute `isExpanded = state.expandedPhases?.[i] ?? (phase.status === 'active')`. (Default-expanded while active; default-collapsed once complete unless the user has expanded.)
    3. Render a container Box with KEY `phase-{phase.name}-{phase.startedAt}` (stable across re-renders; phase name + startedAt never change once a phase is created).
    4. Inside the container:
       - A row: `<Text>` prefix (`'▸ '` when focused, `'  '` otherwise) + `<DPEVPhaseHeader phase={phase} substatus={phase.substatus} />`.
       - If `phase.usage` is set: render a dimmed usage line per D-09/D-11/D-25 (see format string below).
       - If `phase.status === 'active'`: render `<StreamingText text={phase.tokens} />` (keeps live typewriter feel per D-20).
       - Else if `isExpanded`: render `<MarkdownView>{phase.tokens}</MarkdownView>` for the phase body. (D-20: only swap after completion.)
       - Else: render nothing for the body (collapsed).

    Usage line format (D-09, D-11, D-25):
    ```
    in:{in} · out:{out|–} · total:{total|–} · ${cost|–} · [distilled: — | saved: — (v2.0)]
    ```
    - `in:` always shows a number (input tokens; local fallback in Plan 02 means this is always present).
    - `out:`, `total:`: show the integer when non-null, otherwise `–`.
    - `$`: show `cost.toFixed(4)` when non-null, otherwise `–`.
    - Render the bracketed suffix dimmed in the same `<Text>` (or a nested Text with its own dimColor); acceptable to split into two Text nodes within a horizontal Box.

    **Session-summary footer:**
    When `state.status === 'complete'` AND `state.sessionSummary` is defined:
    - Render `<Text dimColor>Session: {totalTokens} tokens · ${totalCostUsd.toFixed(2)}</Text>` just AFTER the existing "Session complete" line.
    - Render `<Text dimColor>Saved via Memory: ${(potentialSavings ?? 0).toFixed(2)} (v2.0)</Text>` just after the Session line.

    **Keyboard input (LIVE mode only — not replay):**
    A `useInput` handler inside `LiveDPEVPanel`:
    - `↑` or `k` → `dispatch({ type: 'PHASE_FOCUS', index: (state.focusedPhaseIndex ?? state.phases.length - 1) - 1 })` (reducer clamps).
    - `↓` or `j` → `dispatch({ type: 'PHASE_FOCUS', index: (state.focusedPhaseIndex ?? 0) + 1 })` (reducer clamps).
    - `Enter` → if `state.focusedPhaseIndex !== undefined` AND `state.phases[focusedPhaseIndex].status !== 'active'` → `dispatch({ type: 'PHASE_EXPAND', index: state.focusedPhaseIndex, expanded: true })`. (Don't "expand" active phases — they're already showing live content.)

      state,
      apiBaseUrl,

      apiBaseUrl: string;

      return (
        <Box flexDirection="column" flexGrow={1}>
          {/* DPEV Phase Accordion with focus + expand + substatus + usage */}
          {state.phases.map((phase, i) => {
            const isFocused = virtualFocusedIdx === i;
            const isExpanded = state.expandedPhases?.[i] ?? (phase.status === 'active');
            const stableKey = `phase-${phase.name}-${phase.startedAt}`;
            return (
              <Box key={stableKey} flexDirection="column">
                <Box>
                  <Text color={isFocused ? 'cyanBright' : undefined}>
                    {isFocused ? '▸ ' : '  '}
                  </Text>
                  <DPEVPhaseHeader phase={phase} substatus={phase.substatus} />
                </Box>

                      {`in:${phase.usage.inputTokens}`}

                      {` · total:${phase.usage.totalTokens ?? '–'}`}
                      {` · $${phase.usage.costUsd !== null ? phase.usage.costUsd.toFixed(4) : '–'}`}
                      {` · [distilled: — | saved: — (v2.0)]`}

                  <Box marginLeft={2}>
                    <MarkdownView>{phase.tokens}</MarkdownView>
                  </Box>
                )}
              </Box>
            );
          })}

          {showCacheHit && state.cacheHit && (

    STEP C — Add keyboard handler to `LiveDPEVPanel`. Inside the `LiveDPEVPanel` component function (after the existing `useCallback` handlers, before `return`):

    ```typescript
    const inputGuardActive =
      !state.pendingApproval &&
      state.status !== 'awaiting-approval' &&
      state.status !== 'plan-approval';

    useInput(
      (input, key) => {
        if (state.phases.length === 0) return;
        const currentIdx = state.focusedPhaseIndex ?? state.phases.length - 1;
        if (key.upArrow || input === 'k') {
          dispatch({ type: 'PHASE_FOCUS', index: currentIdx - 1 });
        } else if (key.downArrow || input === 'j') {
          dispatch({ type: 'PHASE_FOCUS', index: currentIdx + 1 });
        } else if (key.return) {
          const focusedPhase = state.phases[currentIdx];
          if (focusedPhase && focusedPhase.status !== 'active') {
            dispatch({ type: 'PHASE_EXPAND', index: currentIdx, expanded: true });
          }
        } else if (key.escape) {
          dispatch({ type: 'PHASE_EXPAND', index: currentIdx, expanded: false });
        }
      },
      { isActive: inputGuardActive },
    );
    ```
