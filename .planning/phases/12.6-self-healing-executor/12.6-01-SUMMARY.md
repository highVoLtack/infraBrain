## Decisions Made
- Fresh correction prompt per attempt: no previous attempts included (per user decision from research phase)
- Fail-open verification: if LLM generates a non-read verification command, skip verification rather than blocking a successful fix
- Effect verification only for WRITE and DESTRUCTIVE risk, not READ (read commands have no side effects to verify)
- Safety-blocked corrections count as attempts and deduct budget (prevents infinite loop of blocked commands)
- Shell mode detection via needsShell() for corrected commands with pipes/redirects
