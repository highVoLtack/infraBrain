<decisions_made>

### Wake-up Context Layers
- L0 identity: Dynamic from LanceDB metadata (incident count, last activity, top domains) — not static template
- L1 recent: ~500 tokens, last 3-5 incidents as one-liners
- L2 filtered search: Always-on every session (top 3 similar incidents via vector search)
- L3 deep semantic: Only on cache miss AND weak L2 (similarity < 0.7)
- Injection: Dedicated [MEMORY] block between [GROUND TRUTH] and [DISCOVERY]. L0+L1 pinned, L2+L3 evictable

### Knowledge Graph Design
- Separate LanceDB entity table with relationships (not just incident payload metadata)
- Explicit valid_from/valid_to temporal validity on every entity relationship
- Single table with `wing` discriminator column for Wings/Rooms hierarchy
- Same exponential decay formula as Phase 16, but separate lambda in config.json — memory decays slower than cache (architectural knowledge stays relevant months)

### Memory Skill Routing
- LLM intent classification via workerModel (Gemini 1.5 Flash) — no keyword triggers, natural language routing
- Classifier outputs structured JSON: {type, search_query, time_range: {from, to}, format_hint}
- Current date/time injected into classifier system prompt for accurate relative time resolution
- Response format flexible: Gemini 1.5 Pro decides table vs narrative vs both based on query type
- Output Ink-terminal ready (Chalk colors, Box components) for Phase 19 compatibility
