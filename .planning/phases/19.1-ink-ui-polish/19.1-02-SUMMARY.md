- Backward compatibility: handles both dpev_phase_start (new) and phase_start (old) event types so old sessions still replay
- Entity refreshKey incremented on session select and prompt dismiss (two natural trigger points)
- Session filter removed eventCount>0 gate since Plan 01 now provides real targets for in-progress sessions
- 10s polling interval chosen as balance between freshness and network load
