<objective>
Persist SSE streaming sessions to the session store and log DPEV phase transitions as audit events.

Purpose: SSE `/stream/debug` sessions currently create a sessionId but never persist a session record or log DPEV phase events. This makes SSE sessions invisible in the Sessions panel and impossible to replay. This plan adds session persistence (target=prompt, status tracking) and DPEV phase audit logging (alongside existing onEvent SSE emissions) so the history endpoint returns real data and replay can reconstruct the timeline.

Output: Modified stream-debug.ts with session persistence, modified pipeline.ts with DPEV audit logging, extended audit event types.
</objective>
