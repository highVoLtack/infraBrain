<objective>
Wire the resume flow end-to-end: halt persistence in execute route, real runner in resume route, and formatResumeSummary in CLI.

Purpose: Three disconnected pieces prevent resume from working in production: (1) the execute route never persists resumeMetadata/currentPlan to SQLite when executor halts, so resume cannot find interrupted sessions, (2) the resume route uses a stub runner `{ run: async () => ({ stdout: '', stderr: '', exitCode: 0 }) }` instead of real `runCommand`, and (3) `formatResumeSummary` is imported but never called in the CLI resume command.

Output: Resume flow works end-to-end from real execution halts. All tests pass.
</objective>
