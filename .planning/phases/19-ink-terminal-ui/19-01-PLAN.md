<task type="auto" tdd="true">
  <name>Task 2: Create SSE event types, theme, and custom hooks</name>
  <files>src/ui/types.ts, src/ui/theme.ts, src/ui/hooks/useSSE.ts, src/ui/hooks/useResponsive.ts, src/ui/hooks/usePanel.ts, tests/ui/hooks.test.tsx</files>
  <behavior>
    - useResponsive returns 'full' for columns >= 120, 'compact' for 80-119, 'minimal' for < 80
    - usePanel cycles activePanel through 'left' -> 'center' -> 'right' -> 'left' on each call to cyclePanel()
    - useSSE parseSSEStream generator yields {event, data} objects from SSE text chunks
    - theme.riskColor returns green for 'read', yellow for 'write', red for 'destructive', gray for 'blocked'
    - SSEEventMap type covers: dpev:phase, dpev:token, dpev:diagnosis, dpev:cache-hit, dpev:plan, exec:step, exec:approval, dpev:complete, dpev:error
  </behavior>
  <action>
1. Create `src/ui/types.ts` with:
   - `SSEEventMap` interface mapping event names to payload types (see RESEARCH.md Pattern 1 for exact shape):
     - `dpev:phase`: `{ phase: 'discovery' | 'diagnosis' | 'plan' | 'execution' | 'verification'; model: string; status: 'active' | 'complete' }`
     - `dpev:token`: `{ text: string; phase: string }`
     - `dpev:diagnosis`: `{ rootCause: string; correlation: string; structuredDiagnosis: object }`
     - `dpev:cache-hit`: `{ similarity: number; confidence: number; sourceSessionId: string; sourceDate: string; skillName: string; provider?: string; resourceType?: string }`
     - `dpev:plan`: `{ fixPlan: object; planTable: string }`
     - `exec:step`: `{ stepIndex: number; total: number; command: string; risk: string; status: 'pending' | 'running' | 'success' | 'failed' | 'skipped'; stdout?: string; stderr?: string; provider?: string; target?: string }`
     - `exec:approval`: `{ command: string; riskLevel: string; target: string; stepIndex: number }`
     - `dpev:complete`: `{ sessionId: string; status: string }`
     - `dpev:error`: `{ message: string; phase?: string }`
   - `DPEVPhaseState` interface: `{ name: string; model: string; startedAt: number; completedAt?: number; status: 'active' | 'complete' | 'error'; tokens: string }`
   - `DPEVState` interface (see RESEARCH.md Pattern 4 for shape): sessionId, phases array, activePhaseIndex, cacheHit, fixPlan, executionSteps, pendingApproval, status
   - `DPEVAction` discriminated union type for useReducer
   - `StepState` interface: stepIndex, total, command, risk, status, stdout, stderr, provider, target
   - `ApprovalRequest` interface: command, riskLevel, target, stepIndex
   - `LayoutMode` type: `'full' | 'compact' | 'minimal'`
   - `PanelId` type: `'left' | 'center' | 'right'`

2. Create `src/ui/theme.ts` with:
   - `riskColor(risk: string): string` -- returns Ink-compatible color names: 'green' for read, 'yellow' for write, 'red' for destructive, 'gray' for blocked
   - `providerBadge(provider: string): { label: string; color: string }` -- Docker = blue, Postgres = cyan, Nginx = green, default = white
   - `statusIcon(status: string): string` -- 'active' = spinner char, 'complete' = checkmark, 'error' = cross, 'pending' = dot
   - `theme` object with color palette constants: headerBg, panelBorder, panelBorderFocused, activePhaseBg, dimText

3. Create `src/ui/hooks/useSSE.ts` with:
   - `parseSSEStream(response: Response)` async generator function (NOT a hook -- pure async generator for testability). Takes a fetch Response, reads the body stream, parses SSE lines, yields `{ event: string; data: string }` objects. Uses TextDecoder with `{ stream: true }`.
   - `useSSE(url: string, options?: { method?: string; body?: unknown })` custom hook that:
     - Creates AbortController in useEffect
     - Calls fetch() with the url and options
     - Iterates parseSSEStream, dispatching events via a callback
     - Aborts on cleanup (AbortController.abort())
     - Returns `{ connected: boolean; error?: string }`

4. Create `src/ui/hooks/useResponsive.ts` with:
   - `useResponsive()` hook wrapping Ink's `useWindowSize()`. Returns `{ mode: LayoutMode; columns: number; rows: number }` where mode is 'full' (>=120), 'compact' (80-119), 'minimal' (<80).

5. Create `src/ui/hooks/usePanel.ts` with:
   - `usePanel()` hook managing panel focus. Returns `{ activePanel: PanelId; cyclePanel: () => void; setPanel: (id: PanelId) => void }`. cyclePanel cycles left -> center -> right -> left.

6. Create `tests/ui/hooks.test.tsx` with tests for:
   - `parseSSEStream`: mock a ReadableStream with SSE-formatted text, verify yields correct event/data pairs
   - `useResponsive`: test all three breakpoints (mock useWindowSize via vi.mock)
   - `usePanel`: test cycle order and setPanel
   - `riskColor`: test all four risk levels
   - `statusIcon`: test all four status values
