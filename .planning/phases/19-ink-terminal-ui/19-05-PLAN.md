   - Props: `{ apiBaseUrl: string }`
   - On mount: fetch `${apiBaseUrl}/health` to get backend status, inference mode, model list
   - Re-fetch every 30 seconds via setInterval (not aggressive -- status doesn't change frequently)
   - Layout (2-3 lines):
     - Line 1: `InfraBrain v1.3` (bold) | inference mode badge (green "PARALLEL" or blue "SEQUENTIAL") | active model name

   - Props: `{ apiBaseUrl: string; activePanel: PanelId; centerContent: React.ReactNode; onSessionSelect?: (sessionId: string) => void; onEntitySelect?: (entityId: string) => void; showEntityOverlay?: boolean }`
   - Use `useResponsive()` to determine layout mode
   - Full mode (>=120 cols):
     ```jsx
     <Box flexDirection="row" flexGrow={1}>
       <Box flexBasis="20%" borderStyle="single" borderColor={activePanel === 'left' ? theme.panelBorderFocused : theme.panelBorder}>
         <SessionPanel apiBaseUrl={apiBaseUrl} onSelect={onSessionSelect} />
       </Box>
       <Box flexBasis="55%" borderStyle="single" borderColor={activePanel === 'center' ? theme.panelBorderFocused : theme.panelBorder}>
         {centerContent}
       </Box>
       <Box flexBasis="25%" borderStyle="single" borderColor={activePanel === 'right' ? theme.panelBorderFocused : theme.panelBorder}>
         <EntityPanel apiBaseUrl={apiBaseUrl} onSelect={onEntitySelect} />
       </Box>
     </Box>
     ```
   - Compact mode (80-119 cols):
     ```jsx
     <Box flexDirection="row" flexGrow={1}>
       <Box flexBasis="25%">{/* SessionPanel */}</Box>
       <Box flexBasis="75%">{centerContent}</Box>
     </Box>
     {showEntityOverlay && <EntityPanel />}  {/* Overlay triggered by 'g' key */}
     ```
   - Minimal mode (<80 cols):
     ```jsx
     <Box flexGrow={1}>{centerContent}</Box>
     {/* Other panels accessible via Tab cycling overlay */}
     ```
   - Active panel border: bold/colored for focused, dim for unfocused (visual indicator per user decision)

    - EntityPanel top half shows compact tree grouped by provider
    - EntityPanel bottom half shows detail pane for selected entity (type, provider, resourceType, timestamps)

  <action>
1. Create `src/ui/components/SessionItem.tsx`:
   - Props: `{ sessionId: string; status: string; target?: string; skillName?: string; expertDomain?: string; timestamp: string; isActive?: boolean }`
   - Render: `[outcomeIcon] serviceName  expertDomainIcon  timeAgo`
   - Outcome icons: checkmark (completed), cross (failed), hourglass (active/in_progress)
   - Expert domain icons: whale emoji char for Docker, elephant for Postgres, gear for generic (use simple Unicode, not emoji -- per user decision, these are icon indicators)
   - Actually, use simple text badges since terminal emoji support varies: `[D]` for Docker, `[P]` for Postgres, `[N]` for Nginx
   - Active session highlighted with bold text
   - Truncate sessionId to 8 chars for display

2. Create `src/ui/panels/SessionPanel.tsx`:
   - Props: `{ apiBaseUrl: string; onSelect: (sessionId: string) => void; activeFocus?: boolean }`
   - On mount: fetch session list from `${apiBaseUrl}/history?limit=50` (or equivalent endpoint)
   - Group sessions by date:
     - "Today": timestamp within last 24h
     - "Yesterday": 24-48h ago
     - "This Week": 2-7 days ago
     - "Older": > 7 days ago
   - Render each group as a collapsible section (group header, then SessionItem list)
   - Active session always pinned at top, highlighted
   - Navigation: when panel is focused, arrow keys move selection up/down through sessions
   - Enter on a session: call `onSelect(sessionId)` to load replay in center panel
   - '/' key: show search input at top (use @inkjs/ui TextInput or Ink useInput for character capture). Filter sessions by fuzzy matching on target/skillName. Real-time filtering as user types. Esc to dismiss search.
   - Windowing: only render visible sessions (max ~20 at a time to prevent performance issues per RESEARCH.md Pitfall 3)

3. Create `src/ui/components/EntityTree.tsx`:
   - Props: `{ entities: Array<{ id: string; entity_type: string; entity_value: string; provider?: string; isLive: boolean }>; selectedId?: string; onSelect: (id: string) => void }`
   - Group entities by provider (Docker, Postgres, etc.)
   - Render as compact tree:
     ```
     Docker
       [filled] nginx-proxy
       [filled] postgres-demo
     Postgres
       [empty] idle_connections
     ```
   - Filled circle (Unicode) for live entities (current session), empty circle for memory entities
   - Color intensity by recency: bold for live, dim for old (per user decision)
   - Selected entity highlighted with inverse colors or arrow indicator

4. Create `src/ui/components/EntityDetail.tsx`:
   - Props: `{ entity: { entity_type: string; entity_value: string; provider?: string; resourceType?: string; valid_from?: string; valid_to?: string; session_count?: number; incident_ids?: string[] } }`
   - Render detail information:
     - Type: entity_type
     - Provider: provider badge
     - ResourceType: resourceType
     - First seen / Last seen: valid_from / valid_to formatted
     - Sessions: session_count
     - Related incidents: list of incident IDs (truncated)
   - Per user decision: all entity displays must include provider and resourceType

5. Create `src/ui/panels/EntityPanel.tsx`:
   - Props: `{ apiBaseUrl: string; onSelect?: (entityId: string) => void; liveEntities?: Array<{ id: string; entity_type: string; entity_value: string; provider?: string }>; activeFocus?: boolean }`
   - Layout: top half = EntityTree, bottom half = EntityDetail for selected entity
   - On mount: fetch entities from LanceDB (via a new lightweight API endpoint, or embed LanceDB query directly since this runs in the same process)
   - Since InfraBrain is a single-process app and LanceDB is in-process, the EntityPanel can either:
     a. Fetch via API (cleaner, add GET /entities endpoint) -- prefer this for consistency
     b. Import entity store directly (faster, but couples UI to data layer)
   - Choose (a): add a simple GET /entities endpoint to server.ts that calls `entityStore.getActive()` and returns JSON. Keep this minimal.
   - Merge API entities with `liveEntities` prop (entities discovered in current session, passed from DPEVPanel)
   - Navigation: arrow keys select entity in tree, Enter expands detail, Esc collapses detail
   - '/' key for entity search (filter by name/type)
   - Live update: newly discovered entities (from liveEntities prop) appear with "NEW" marker that fades after 5 seconds

6. Add tests to `tests/ui/layout.test.tsx`:
   - SessionItem: render with completed status, verify checkmark appears
   - SessionPanel: render with mock session data, verify date grouping headers appear
   - EntityTree: render with mixed live/memory entities, verify provider grouping
   - EntityDetail: render with entity data, verify provider and resourceType displayed
