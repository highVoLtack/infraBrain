1. Create `src/ui/layout/StatusOverlay.tsx`:
   - Props: `{ apiBaseUrl: string; onDismiss: () => void }`
   - On mount: fetch data from `/health` and `/status` endpoints
   - Layout: full-width overlay Box with borderStyle and distinct background color
   - Content sections (hard facts per user decision -- "technical cockpit"):
     - **Backends**: table showing baseUrl, status (connected/disconnected), latency ms, models available
     - **Model Assignments**: table showing role -> model mapping (from /health registry)
     - **Cache Stats**: hit rate (if available), total entries, avg confidence
     - **Memory Stats**: incident count, entity count, WAL size
     - **Context Window**: token usage visualization (text progress bar showing current/max)
     - **Compression Efficiency**: placeholder text "Caveman/Perc integration: v2.0" (per deferred decision -- Phase 19 pre-builds UI hook only)
   - Esc key: call `onDismiss()` to close overlay
   - Use `useInput` with `isActive: true` to capture Esc (per RESEARCH.md Pitfall 6, other panel focus hooks should be disabled when overlay is active)

2. Create `src/ui/App.tsx`:
   - Props: `{ apiBaseUrl: string; initialCommand?: { type: string; args: string[] } }`
   - State management:
     - `usePanel()` for panel focus cycling
     - `useResponsive()` for layout mode
     - `showStatusOverlay` boolean state
     - `showEntityOverlay` boolean state (for compact mode 'g' toggle)
     - `activePrompt` string state (current debug prompt being executed)
     - `replaySession` state (selected past session for replay)
     - `inputMode` state: 'normal' | 'command' (for accepting /infra: commands)
   - Layout:
     ```jsx
     <Box flexDirection="column" width="100%" height="100%">
       <HeaderBar apiBaseUrl={apiBaseUrl} />
       <PanelLayout
         apiBaseUrl={apiBaseUrl}
         activePanel={activePanel}
         centerContent={
           activePrompt
             ? <DPEVPanel apiBaseUrl={apiBaseUrl} prompt={activePrompt} />
             : replaySession
               ? <DPEVPanel replaySession={replaySession} />
               : <IdleView />
         }
         onSessionSelect={handleSessionSelect}
         showEntityOverlay={showEntityOverlay}
       />
       {showStatusOverlay && <StatusOverlay apiBaseUrl={apiBaseUrl} onDismiss={() => setShowStatusOverlay(false)} />}
       {inputMode === 'command' && <CommandInput onSubmit={handleCommand} />}
     </Box>
     ```
   - Global keyboard handling via `useInput`:
     - `Tab`: call `cyclePanel()` (unless overlay is open)
     - `s`: toggle `showStatusOverlay`
     - `g`: toggle `showEntityOverlay` (only in compact mode)
     - `Esc`: dismiss overlay, or return to live session from replay, or exit command input
     - `/`: activate search in the focused panel (session search in left, entity search in right)
     - Typing `/infra:` prefix: switch to command input mode
   - When overlay is active: disable panel focus cycling (set isActive flags per RESEARCH.md Pitfall 6)
   - IdleView: simple component showing "InfraBrain v1.3" with help text for available commands
   - CommandInput: text input component for typing /infra: commands. On submit, parse command and execute:
     - `/infra:debug "prompt"` -> set activePrompt (triggers DPEVPanel with SSE)
     - `/infra:status` -> toggle status overlay
     - `/infra:history` -> focus left panel
     - `/infra:resume` -> load resumable session
   - Session replay: when `handleSessionSelect(sessionId)` is called, fetch session data from /history and build a DPEVState for replay mode. Show "Return to live" button.

   - Test StatusOverlay renders backend section and Esc dismisses

   - Keep ALL existing initialization code unchanged (config, LLM, state, audit, skills, cache, server)
   - Replace the interactive mode section:
     ```typescript

     // NEW: Render Ink app

       React.createElement(App, { apiBaseUrl }),
       { exitOnCtrlC: true }
     );
     await waitUntilExit();
     ```
   - One-shot mode (CLI args present) remains unchanged -- bypass Ink, use Commander directly
   - Add `--json` flag detection: if `args.includes('--json')`, also bypass Ink and use existing formatters + console.log output path
   - Keep `startRepl` import but comment it out (or remove) -- it's fully replaced by Ink
   - Signal handlers: register SIGINT and SIGTERM handlers that call Ink's cleanup to restore terminal state (per RESEARCH.md Pitfall 5):
     ```typescript
     process.on('SIGINT', () => { server.close(); db.close(); process.exit(0); });
     process.on('SIGTERM', () => { server.close(); db.close(); process.exit(0); });
     ```
   - IMPORTANT: Do NOT call console.log from within the Ink render tree. Move all startup console.log messages to BEFORE the Ink render call. Ink takes over stdout. (per RESEARCH.md Pitfall 2)

     - `/infra:status` -> parsed by CommandInput, toggles StatusOverlay

     - `/infra:resume` -> parsed by CommandInput, loads resumable session
   - Ensure the existing registerCommands function still works for one-shot mode (no changes needed)
   - The key insight: Commander handles arg parsing for one-shot mode. In interactive Ink mode, the App component handles command routing internally via the CommandInput component. No readline needed.
