    - Test: detectLogFormat identifies syslog format (BSD-style "Mon DD HH:MM:SS hostname")
    - Test: detectLogFormat defaults to syslog for unrecognized formats
    - Test: parseSyslog extracts timestamp, level, message, source from BSD syslog lines
    - Test: parseJsonLog extracts fields from JSON structured log lines, handles missing fields gracefully
    - Test: parseDockerLog extracts timestamp and container info from Docker log format
    - Test: parseJournaldLog extracts fields from journald-style output
    - Test: parseLog dispatches to correct parser based on detected format
    - Test: All parsers preserve the raw original line in LogEntry.raw
    - Test: Parsers handle malformed lines gracefully (skip or return partial LogEntry with raw line)
  </behavior>
  <action>
    1. Create src/log-analysis/types.ts:
       - LogFormat enum: SYSLOG, JSON, DOCKER, JOURNALD
       - LogEntry interface: { timestamp: string (ISO 8601), level: string (normalized: error/warn/info/debug), message: string, source: string, raw: string }
       - ParsedLog interface: { format: LogFormat, entries: LogEntry[], unparseable: string[] }

    2. Create src/log-analysis/detector.ts:
       - detectLogFormat(sample: string): LogFormat
       - Heuristics (in order): JSON ({), Docker (ISO8601+Z), journald ("-- Journal" or systemd unit pattern), syslog (BSD date), default syslog
       - Implementation per research Pattern: Log Format Auto-Detection

    3. Create four parsers in src/log-analysis/parsers/:
       - syslog.ts: parseSyslog(lines: string[]): LogEntry[] -- BSD format "Mon DD HH:MM:SS hostname process[pid]: message". Normalize level from message keywords (error/warning/notice/info). Source = process name.
       - json.ts: parseJsonLog(lines: string[]): LogEntry[] -- Each line is a JSON object. Map common field names (level/severity, msg/message, time/timestamp/@timestamp, service/source). Handle parse failures gracefully.
       - docker.ts: parseDockerLog(lines: string[]): LogEntry[] -- Format: "TIMESTAMP STREAM_TYPE message" where TIMESTAMP is ISO8601. Source = "docker". Level inferred from stderr (error) vs stdout (info).
       - journald.ts: parseJournaldLog(lines: string[]): LogEntry[] -- Format from `journalctl --no-pager`. Extract timestamp, unit name as source, priority as level, message body.
       - index.ts: parseLog(text: string): ParsedLog -- Calls detectLogFormat on first few lines, dispatches to correct parser, returns ParsedLog with format and entries.

    4. Create test fixtures:
       - tests/fixtures/logs/syslog.log: 10-15 lines of realistic BSD syslog (mix of error/info/warning)
       - tests/fixtures/logs/json.log: 10-15 lines of JSON structured logs with varying field names
       - tests/fixtures/logs/docker.log: 10-15 lines of Docker container log output
       - tests/fixtures/logs/journald.log: 10-15 lines of journalctl output

    5. Write tests in tests/log-analysis/parsers.test.ts covering all behaviors above. Test against fixture files.

    All imports use .js extensions per project ESM convention.
